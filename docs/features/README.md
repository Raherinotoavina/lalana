# Post-V1 feature backlog

Ideas planned after V1. This is a backlog, not a commitment: promote an item into a
numbered phase only after its prerequisites, product value, and scope are validated.

| Idea | Why | Notes |
|---|---|---|
| Identity verification (CIN) | Trust and safety | Manual or provider-based review |
| Shareable web trip pages | Trips shared in Facebook groups open without the app | Expo Router web, "Ouvrir dans l'app" |
| Recurring trips (Mon–Fri) | Daily commuters publish once | Removed from the V1 publishing flow for simplicity |
| Saved searches and alerts | Notify passengers when a matching trip appears | Needs Phase 08 |
| Instant booking for trusted drivers | Faster urban bookings | Skips the driver acceptance step |
| Live trip sharing and SOS | Passenger safety | Background location constraints |
| Free-form address search and map pins | Places outside the curated list | Geocoding quality in Antananarivo |
| Photos in chat | Meeting point pictures | Storage cost |
| Driver payouts | Only if fares are paid in the app | Depends on Phase 10 provider |
| More cities | Growth | After the first corridors work |
